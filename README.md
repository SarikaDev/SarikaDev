### 🚀 Featured Projects

#### [Vault](https://money-puce-ten.vercel.app) — Color-Coded Personal Finance Engine
**Next.js 16 · TypeScript · Tailwind CSS v4 · Zustand · TanStack Query · Supabase · PostgreSQL · Vercel**

A dual-vault budgeting system where each spending envelope carries a **typed financial behaviour** — defining how it handles overspend, underspend, and month-end rollover — rather than treating all categories identically.

**What makes this different:**
- **Procedure-first PostgreSQL architecture** — every write is routed through stored functions exclusively; triggers block direct table mutations at the database level, making an entire class of data corruption bugs architecturally impossible
- **Row Level Security on every table** with proper `WITH CHECK` clauses — financial data access is controlled at the database layer, fully independent of frontend logic
- Deliberately scoped feature set — studied what *not* to build as carefully as what to build
- Shipped end-to-end solo: database design, full-stack implementation, documentation site, and Vercel deployment

→ [Live App](https://money-puce-ten.vercel.app) · [Docs](https://funny-florentine-523c81.netlify.app)

#### [Portfolio CMS](https://sarikaa-portfolio.vercel.app/portfolio) — Self-Managing Portfolio System
**Next.js · TypeScript · Tailwind CSS · Supabase · PostgreSQL · Supabase Storage · Vercel**

A portfolio backed by an **admin panel** — new projects are published to the public site through a dashboard with zero code changes or redeployments.

**Key details:**
- Resume management layer: uploading a new version automatically replaces the previous file in Supabase Storage — the public download link always serves the latest version
- Secured with Supabase Auth (Google OAuth) — deliberately skipped RLS since it's single-user, applying the right level of security for the actual threat model rather than over-engineering it
- Treats the portfolio itself as a maintainable product

→ [Live Site](https://sarikaa-portfolio.vercel.app/portfolio)
